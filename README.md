# Repository `.github` (Salus)

Workflow condivisi e **template** per i plugin WordPress del workspace.

## Template Salus

Sorgente unica per la cartella `salus/` copiata in ogni plugin: [templates/salus/TEMPLATE.md](templates/salus/TEMPLATE.md)

- File condivisi: `manifest.json`
- Plugin con `salus/`: `plugins.json`
- Flusso allineamento: regola Cursor `salus-plugins-standards.mdc` (sezione *Allineamento template*)

## Workflow

- `workflows/wp-plugin-auto-release.yml` — release automatiche plugin (tag + ZIP)

## Regole Cursor

In `.cursor/rules/` — standard condivisi workspace (`salus-plugins-standards.mdc`, ecc.)
